# PBX 상담원 현대화 디자인

승인: 2026-09-07 사용자 시안 승인 및 적용 요청.
대상: apps/desktop-win (WPF). 로그인, 대기, 통화 화면과 공통 컨트롤, 앱/트레이 아이콘.

- 밝은 회색 #f4f5fa 바탕, 흰 카드, 인디고 #5a55d6 주요 동작. 다크 테마는 같은 구조와 역할을 사용한다.
- 카드 반경 16, 입력/버튼 반경 10. 기존 창 크기와 모드별 크기 계약은 유지한다.
- 대기는 신원/빠른 도구, 상태와 발신 카드, 지난 통화/설정/로그아웃, 연결 상태 순서다.
- 로그인은 동일한 헤드셋 브랜드와 인사말, 기존 입력/옵션/오류/서버 설정을 유지한다.
- 통화는 번호/통화 시간, 메모 또는 키패드, 통화 제어, 종료 버튼을 배치한다.
- 앱과 트레이는 동일한 인디고 헤드셋을 사용하고 트레이 상태는 배지로 보존한다. 상태 색만으로 판단하지 않도록 기존 툴팁을 유지한다.
- 숨김/활성 조건, 바인딩, 단축키, 전화기 등록 안내, 당겨받기, 발신번호 선택, 업데이트 안내를 유지한다.
- 기존 기능 화면에도 공통 팔레트와 컨트롤을 적용한다. 서버/API/인증/통화 상태 로직은 변경하지 않는다.
- 빌드, 기존 테스트, 실제 WPF 오프라인 렌더로 최소 크기/라이트/다크/상태별 레이아웃을 확인한다. 실제 PBX 통화 검증 여부는 별도로 기록한다.
