# 데스크톱 상담원 앱 — 다크 콘솔 디자인

**작성일**: 2026-08-23
**대상**: `apps/desktop-win`
**캔버스**: https://claude.ai/code/artifact/00f6b6d3-872f-4ede-86bd-e1334e2505e9

`2026-08-23-desktop-dark-console/` 의 `.dc.html` 은 위 캔버스의 원본이다. 캔버스를 고치려면 이 파일을 고친 뒤 다시 올린다.
파일 하나가 화면 하나이고, `canvas.json` 이 배치와 페이지를 정한다.

## 왜 다크인가

상담실은 어둡고 상담원은 같은 화면을 8시간 본다. 눈부심이 줄고, **상태 색이 또렷해진다.**

대가도 있다. 윈도우의 다른 창과 따로 놀고, 밝은 사무실이 섞여 있으면 밝은 테마를 함께
유지해야 한다. 그 결정은 아직 안 났다.

## 색이 상태를 나른다

| 색 | 값 | 뜻 |
|---|---|---|
| 초록 | `#35c48c` | 대기 · 통화 중 (정상) |
| 파랑 | `#4ea3dd` | 호 배정 대기 · 전환 |
| 호박 | `#e0a83a` | 남은 시간 · 오래 기다린 호 |
| 빨강 | `#ff6b6b` | 끊기 · 거절 |

바탕은 `#12161d`, 면은 `#1a202a`, 올라온 면은 `#222a35`, 테두리는 `#2a3240`,
글자는 `#e6ecf3` / 흐린 글자 `#8896a8`.

**초록을 아이콘 색 후보에서 뺀 이유가 여기 있다.** 초록은 이 UI 에서 "대기" 라는 상태를
뜻하게 됐다. 아이콘까지 초록이면 트레이에서 상태 표시와 앱 표시가 같은 색이 되어,
상태가 바뀌었는지가 흐려진다.

## 스크롤 규칙

**창 전체는 스크롤되지 않는다. 목록과 설정 내용은 자체 스크롤한다.**

그래서 대기 목록을 3건(타일 6건)에서 잘라내고 "외 N건" 으로 숨기던 처리는 없앨 수 있다.

## 앱 아이콘

헤드셋 실루엣, 청록 `#0f766e`. 생성기는 `apps/desktop-win/tools/make-app-icon.py` 이고
결과물은 `apps/desktop-win/src/KAster.Desktop.App/Assets/kaster-agent.ico` (256/128/64/48/32/16).

크기마다 그림이 다르다 — 64 아래로는 마이크 붐을 빼고, 작아질수록 헤드밴드를 굵힌다.
같은 그림을 그냥 줄이면 16px 에서 회색 덩어리가 된다.

**트레이 아이콘은 바꾸지 않았다.** 그건 상태 색 원이고, 16px 에서 알아볼 수 있는 것은
색뿐이라는 판단이 이미 `TrayIconArt` 에 적혀 있다. 거기에 헤드셋을 넣으면 상태 구분이 사라진다.
