# PBX 운영 액션 설계 메모

## 목적

시스템 재시동과 포트 초기화는 일반 설정 기능이 아니라 장애 대응 운영 액션이다. 관리자 설정 화면에 단순 버튼으로 넣지 않고 권한, 영향 범위, 감사 로그, 실행 결과를 갖춘 운영 절차로 분리한다.

## 시스템 재시동

대상 분리:

- CTI 서버 프로세스
- PBX 서버 프로세스
- 특정 서비스 단위 재시작

필수 보호 장치:

- 운영자 권한 확인
- 2단계 확인
- 실행 전 영향 범위 표시
- 감사 로그 기록
- 실행 결과 상태 저장

초기 운영 방식:

- UI 버튼보다 운영 runbook과 보호된 관리자 API 정책을 먼저 만든다.
- 실제 재시동 실행은 운영 배포/장애 대응 절차와 묶어 검토한다.

## 내선/국선 포트 초기화

정의가 필요한 작업 유형:

- 통화 채널 강제 종료
- 단말 등록 해제 또는 재등록 유도
- 특정 국선 회선 세션 초기화
- PBX 설정 DB 초기화

처리 원칙:

- 안전한 통화 채널 정리와 위험한 설정 초기화를 분리한다.
- 통화 중 고객 영향이 있으므로 실행 전 영향 범위를 표시한다.
- 모든 실행은 감사 로그와 결과 상태를 남긴다.
- PBX 설정 DB 초기화는 별도 승인 절차 없이는 UI에 노출하지 않는다.
