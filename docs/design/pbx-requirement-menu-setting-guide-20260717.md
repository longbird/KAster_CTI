## 1. 목적

기존 디지털 키폰 PBX 참조 기능을 현재 CTI 관리자 화면 기준으로 다시 매칭한다. 이 문서는 운영자와 개발자가 각 요구사항을 어느 메뉴에서 설정하는지, 설정 시 어떤 값을 넣어야 하는지, 현재 수용 여부가 무엇인지 빠르게 확인하기 위한 요약서다.

원격 접속 기준 URL: `http://49.247.46.86:5174`

## 4. 운영자가 자주 쓰는 설정 흐름

### 4.1 지사 DID가 ARS로 들어오게 설정

1. `PBX 설정 > IVR 메뉴`에서 안내 멘트, 메뉴 멘트, 키 입력 대기시간, DTMF 키별 호 분배룰을 등록한다.
2. `PBX 설정 > DID`에서 DID를 추가하거나 수정한다.
3. 연결 방식을 `IVR 메뉴`로 선택하고 생성한 IVR 메뉴를 지정한다.
4. `지사 관리`에서 해당 지사에 DID를 연결한다.
5. `.conf 미리보기`와 운영 PBX 인입 테스트로 실제 분기 결과를 확인한다.

### 4.2 DID를 특정 상담원에게 직접 착신

1. `상담원 설정`에서 대상 상담원의 내선이 활성 상태인지 확인한다.
2. `PBX 설정 > DID`에서 DID를 추가하거나 수정한다.
3. 연결 방식을 `내선 직결`로 선택한다.
4. `직접 착신 내선`에서 상담원을 선택하고 저장한다.
5. 부재, 무응답, 업무시간 분기가 필요하면 `착신전환 설정` 또는 1인 `호 분배룰` 연결을 검토한다.

### 4.3 호 분배룰의 외부 착신 방식 설정

1. `호 분배룰 설정`에서 분배룰을 추가하거나 수정한다.
2. `외부 착신 방식`을 선택한다.
3. 순차/분배 방식이면 상담원 또는 상담원 그룹 멤버와 순위를 구성한다.
4. 무조건 착신이면 대상 유형과 대상 값을 지정한다.
5. 최대 대기시간, 링 타임아웃, 후처리 시간을 운영 기준에 맞게 조정한다.

### 4.4 착신전환 조건 설정

1. `착신전환 설정`에서 규칙을 추가한다.
2. 대상 DID를 선택한다.
3. 전환 방식을 `외부번호`, `내선`, `호 분배룰` 중 하나로 선택한다.
4. 착신 조건을 `즉시`, `대기시간 초과`, `상담원 없음` 중 하나로 선택한다.
5. 시간 조건이 있으면 적용 방식을 `요일/시간 지정`으로 바꾸고 시간표를 추가한다.

### 4.5 다중 국선 기본 발신 그룹 구성

1. `PBX 설정 > 트렁크`에서 각 통신사 또는 회선별 트렁크를 등록한다.
2. 트렁크의 Host, 포트, 인증, From Domain, 코덱, 표시번호를 입력한다.
3. 같은 화면의 `국선 그룹` 영역에서 그룹을 추가한다.
4. 멤버 트렁크와 우선순위를 지정하고 `기본 발신 그룹`을 활성화한다.
5. `.conf 미리보기`에서 발신 경로에 국선 그룹 멤버가 반영되는지 확인한다.
6. 운영 PBX에서 주 회선 장애 우회와 원복을 검증한다.

### 4.6 단축 발신 등록

1. `PBX 설정 > 단축 발신`으로 이동한다.
2. 단축번호, 대상번호, 표시명, 설명을 입력한다.
3. 단축번호는 내선 번호나 외부 발신 패턴과 충돌하지 않게 정한다.
4. 대상번호가 외부번호이면 기존 발신번호 정책과 국선 그룹 경로의 영향을 받는다.

### 4.7 번호 자원에서 설정 화면으로 이동

1. `DID / 내선` 메뉴에서 DID, 내선, 호 분배룰 번호, 기능코드를 확인한다.
2. 충돌 또는 확인할 항목의 `설정 열기`를 누른다.
3. DID는 `PBX 설정 > DID`, 상담원 내선은 `상담원 설정`, 분배룰 번호는 `호 분배룰 설정`, 기능코드는 `통화 현황 조회`의 기능 안내로 이동한다.

## 5. 불수용 및 보류 기준

| 항목 | 기준 |
|---|---|
| 실시간 통화 감청 | 정책상 지원하지 않는다. 메뉴/API/기능코드 모두 만들지 않는다. |
| ARS 번호 별도 관리 | ARS는 번호 자원이 아니라 DID 이후 처리 흐름이다. |

| 포트 DB 초기화 일반 노출 | 장애 복구 전용이며 강권한/감사로그 없이는 제공하지 않는다. |

## 7. 우선 적용 순서

1. 운영 필수: DID, IVR, 호 분배룰, 착신전환, 내선 표시명, 내선 잠금, 시간 동기화.
2. 운영 안정화: 공휴일, 시간별 라우팅, 대리응답 제한 기능, 번호 자원 충돌 확인.
3. 발신 안정화: 트렁크 표시번호, 국선 그룹, 다중 국선 장애 우회 검증.
4. 외부 연동: SMDR TCP Call Report 포트 개방, 타사 CID 프로그램 접속, 삼성 OfficeServ 계열 CDR 고정폭 레코드 수신/파싱 검증.
5. 편의 기능: 단축 발신, 도움말 자동 구축, 공용 운영 가이드.
6. 보류 유지: 실시간 감청, 키버튼/전화기 버튼, PBX COS 전체 복제, 포트 DB 초기화 일반 노출.
