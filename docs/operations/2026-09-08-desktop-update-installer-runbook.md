# PBX 상담원 1.0.1 설치 및 필수 업데이트

작성일: 2026-09-08

## 설치 파일

`apps/desktop-win/release/KAsterAgent-1.0.1-Setup.exe`는 Windows x64용이며 .NET 런타임을 포함한다. 새 디자인, 통일된 아이콘, 발신 키패드, 필수 업데이트 제한을 포함한다.

기존 앱에서 통화를 마치고 앱을 종료한 뒤 설치 파일을 실행한다. 기존 설치 경로에 덮어쓰며 사용자 설정과 로그인 저장소는 유지한다. 새 설치는 사용자 권한으로 진행된다. 설치 후 앱 설정에서 버전 1.0.1을 확인한다.

## 업데이트 정책

- 일반 릴리스: 로그인 시 및 6시간마다 확인한다. 사용자가 통화가 없을 때 설치 파일을 받고, 직접 설치한다.
- 필수 릴리스: `mandatory=true` 또는 현재 버전이 `minimumRequiredVersion`보다 낮으면 새 발신, 당겨받기, 새 수신 응답, 큐 제안 수락, 대기 복귀를 제한한다.
- 필수 지정 전에 이미 울리거나 연결된 통화와 이미 요청한 발신은 마칠 수 있다. 통화 종료, 보류·전환 등 진행 중 통화 제어는 유지한다.
- 통화가 끝나면 자리비움을 요청한다. 실패 시 30초 간격으로 재시도한다. 후처리 중에도 설정과 다운로드를 사용할 수 있다.
- 설치 파일 다운로드의 SHA-256 검증은 유지한다. 앱이나 설치 프로그램을 강제로 종료·실행하지 않는다. 파일 다운로드만으로 제한이 해제되지는 않는다.
- 확인된 필수 릴리스는 서버 주소·상담원별로 저장하여 재시작과 확인 실패에도 유지한다. 필요한 버전 설치 또는 서버에서 필수 지정 철회가 확인되면 해제된다.

이 제한은 1.0.1부터 클라이언트가 적용한다. 1.0.0에는 강제 지정이 안내 문구로만 보이므로 먼저 1.0.1을 설치해야 한다. 물리 전화기에서 직접 거는 통화나 다른 클라이언트까지 차단하는 서버 권한 정책은 아니다. 처음 서버에 접속하지 못해 필수 릴리스를 확인한 적이 없는 경우 일반 동작을 유지한다.

## 생성과 서버 등록

PowerShell에서 저장소 루트를 기준으로 생성한다. 기존 `release/`는 재생성되므로 보존할 설치 파일은 미리 복사한다.

```powershell
pwsh -File apps/desktop-win/tools/build-release.ps1 -Version 1.0.1
```

서명 인증서를 설정한 운영 빌드는 `-RequireSign`을 추가한다. 이번 로컬 산출물은 인증서가 설정되지 않아 서명되지 않았다.

서버에 배포할 때는 생성된 `release.json`의 파일 크기와 SHA-256을 그대로 사용한다. 아래 명령은 Bash 및 jq가 설치된 배포 환경에서 실행한다. `--tenant`에는 실제 대상 테넌트 UUID를 지정한다. 서버 주소와 파일 경로는 스크립트의 환경 변수 설정을 확인한다.

```bash
# 일반 업데이트로 등록
./scripts/publish-desktop-release.sh --tenant "$TENANT_ID" --release apps/desktop-win/release/release.json

# 필요한 경우 전체 구버전을 필수 업데이트 대상으로 등록
./scripts/publish-desktop-release.sh --tenant "$TENANT_ID" --release apps/desktop-win/release/release.json --mandatory

# 특정 버전 미만만 필수 지정
./scripts/publish-desktop-release.sh --tenant "$TENANT_ID" --release apps/desktop-win/release/release.json --minimum 1.0.1
```

등록 전에 같은 인수에 `--dry-run`을 추가하여 대상과 메타데이터를 확인한다. 같은 릴리스를 일반 등록 명령으로 다시 등록하면 필수 플래그와 최소 버전이 해제된다. 실행 중 클라이언트는 다음 정기 확인 또는 ‘지금 확인’에서 변경을 반영한다. 릴리스 회수 후 상담 대기 복귀는 사용자가 선택한다.

이번 작업에서는 설치 파일과 배포 메타데이터를 로컬에 생성한다. 서버 등록 및 실제 상담원 PC 업그레이드는 별도 배포 단계다.

## 검증

- Release 전체 테스트 733개 통과. 일반 업데이트 유지, 필수 발신/수신/제안 제한, 진행 중 통화 유지, 후처리 접근, 재시작 유지, 확인 실패 유지 및 철회 저장을 포함한다.
- WPF 화면 42개 오프라인 렌더링. 최소 크기의 필수 업데이트 안내와 통화 화면 안내를 확인했다.
- 실제 PBX 통화, 설치 프로그램 실행, 서버 릴리스 등록은 실행하지 않았다.
