# PBX 상담원 1.0.2 닫기 및 트레이 수신

## 사용 방법

닫기(X 또는 Alt+F4)를 누르면 다음 동작을 선택한다. 로그인 전에도 동일하다.

- **트레이로 숨기기**: 창을 숨기고 상담 상태, 서버 연결, 전화 연결을 유지한다. 기본 선택이다.
- **앱 종료**: 앱을 완전히 종료한다. 이후 수신 알림이 오지 않으며 진행 중 소프트폰 통화가 끊어질 수 있다.
- **취소** 또는 선택창 닫기: 원래 화면을 유지한다.

숨긴 상태에서 큐 통화 제안이나 내선 직접 수신이 들어오면 Windows 트레이 알림을 표시한다. 알림을 클릭하면 현재 통화 화면으로 복귀한다. 트레이 아이콘 더블클릭 또는 ‘창 열기’ 메뉴로도 복귀한다. 트레이의 ‘종료’ 메뉴는 명시적인 앱 종료다.

숨기는 동작은 자리비움으로 변경하지 않는다. 이미 자리비움 상태였다면 그 상태가 유지되므로 큐 배정도 기존 상태를 따른다. Windows에서 앱 알림을 차단한 경우 트레이 알림 표시가 제한될 수 있다.

기존 ‘닫기를 누르면 트레이로 내리기’ 설정은 선택창으로 대체했다. 1.0.1의 필수 업데이트 제한은 유지한다.

## 설치 및 검증

설치 파일: `apps/desktop-win/release/KAsterAgent-1.0.2-Setup.exe`. 통화를 마치고 앱을 종료한 뒤 실행한다. Windows x64 및 .NET 런타임 포함 구성이다.

- Release 테스트 734개 통과. 직접 수신 알림의 중복 방지와 응답 후 알림 해제를 추가 검증했다.
- 닫기 선택창 XAML 로드 및 오프라인 렌더링 확인.
- 기존 트레이 알림 클릭 → 창 복원 연결은 코드로 확인했다. 실제 PBX 수신 및 Windows 알림 클릭은 현장 검증이 필요하다.
- 설치 파일은 미서명이며 서버 등록은 수행하지 않았다.
