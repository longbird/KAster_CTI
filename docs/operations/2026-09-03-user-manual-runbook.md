## 1. 구성과 용어

비유하면 **PBX 는 교환대**, **CTI 서버는 교환대 옆에 앉은 비서**, **각 앱은 상담원과 관리자가 비서와 대화하는 창**이다.
전화는 교환대가 연결하고, 비서가 "누가 누구와 통화 중인지"를 적어 두었다가 모든 창에 알려 준다. 어떤 창도 교환대를 직접 만지지 않는다.

### 1.1 구성 요소

| 구성 요소 | 하는 일 | 접속 주소 |
|---|---|---|
| PBX | 통신사 회선을 받아 안내(ARS)·대기(큐)·상담원 연결·녹취를 한다 | 상담원은 직접 접속하지 않는다 |
| CTI 서버 | PBX 이벤트를 통화 세션으로 정리하고, 앱에 실시간으로 알리고, 설정을 PBX 에 반영한다 | `https://<API 도메인>` |
| 상담원 데스크톱 앱 "PBX 상담원" | Windows 소프트폰 + 상담 화면. 책상 전화기 자리에서도 화면만 쓸 수 있다 | 설치 파일 |
| 상담원 웹 앱 | 브라우저 상담 화면. 통화는 책상 전화기나 데스크톱 앱이 한다 | `https://<상담원 도메인>` |
| 관리자 콘솔 | 실시간 현황 · 보고서 · 운영 설정 · PBX 설정 반영 | `https://<관리자 도메인>` |
| 플랫폼 관리 화면 | 사이트(테넌트)별 기능 개폐 | `https://<관리자 도메인>/platform/login` |

### 1.2 용어

| 용어 | 뜻 | 관리자 콘솔의 메뉴 |
|---|---|---|
| 테넌트 | 한 회사(사이트). 모든 데이터는 테넌트 안에서만 보인다 | — |
| 지사 | 테넌트 안의 사업장 단위. DID·발신번호·멘트를 지사별로 묶는다 | 지사 관리 |
| DID | 고객이 거는 착신 번호 | PBX 설정 > DID |
| 호 분배룰 | 대기열(큐). 상담원에게 전화를 나눠 주는 규칙 | 호 분배룰 설정 |
| 상담원 그룹 | 상담원 묶음. 분배룰 멤버로 통째로 넣는다 | 상담원 그룹 |
| 내선 | 상담원 전화기(소프트폰 포함)의 번호 | 상담원 설정 |
| 트렁크(국선) | 통신사 회선 | PBX 설정 > 트렁크 |
| 국선 그룹 | 발신에 쓸 트렁크 묶음과 우선순위 | PBX 설정 > 트렁크 > 국선 그룹 |
| 착신전환 | 조건(즉시·대기 초과·상담원 없음·시간표)에 따라 다른 곳으로 보내는 규칙 | 착신전환 설정 |
| IVR 메뉴 / ARS 플로우 | 고객에게 안내를 틀고 번호를 받아 분기하는 시나리오. ARS 플로우는 다단계 그래프 | PBX 설정 > IVR 메뉴 / ARS 플로우 빌더 |
| 멘트 | 안내 음성 파일 | 멘트 관리 |
| 기능코드 | 전화기에서 눌러 쓰는 기능 번호 (대리응답 등) | PBX 설정 > 기능코드 |
| 제안 | 전화를 연결하기 전에 상담원에게 "받으시겠습니까?"를 묻는 단계 | 호 분배룰 설정의 수락 대기시간 |
| 후처리 | 통화가 끝난 뒤 메모·분류를 적는 시간 | 호 분배룰 설정의 후처리 시간 |
| 당겨받기 | 다른 자리에서 울리거나 큐에서 기다리는 전화를 내가 받는 것 | 기능코드 `*8` (기본) |

### 1.3 상태

**통화 상태** (모든 화면이 같은 값을 쓴다)

| 값 | 화면 표시 | 뜻 |
|---|---|---|
| NEW | 신규 | 인입 감지, 아직 아무 데도 배정 안 됨 |
| IVR | IVR | 안내 듣는 중 |
| QUEUED | 대기 | 큐에서 상담원을 기다림 |
| RINGING_AGENT | 벨 울림 | 상담원 전화기가 울리는 중 |
| TALKING | 통화 중 | |
| HOLD | 보류 | 사이트가 보류 기능코드를 설정한 경우에만 나타난다 |
| TRANSFERRING | 전환 중 | |
| AFTER_CALL_WORK | 후처리 | |
| ENDED | 종료 | |

**근무 상태**

| 값 | 표시 | 전화가 배정되는가 |
|---|---|---|
| AVAILABLE | 대기 | 배정된다 |
| RINGING / TALKING / AFTER_CALL_WORK | 벨 울림 / 통화 중 / 후처리 | 시스템이 바꾼다 |
| BREAK / MEAL / TRAINING | 휴식 / 식사 / 교육 | 배정되지 않는다 |
| MANUAL_PAUSED | 일시정지 | 배정되지 않는다. 데스크톱 앱을 트레이로 내리면 이 상태가 된다 |

### 1.4 역할

| 역할 | 할 수 있는 것 |
|---|---|
| agent | 상담원 앱. 관리자 콘솔은 대시보드만 |
| supervisor | 관리자 콘솔 전체 메뉴 (기본값). 권한 관리에서 줄일 수 있다 |
| admin | 관리자 콘솔 전체 + 일부 등록 기능(예: ARS 외부 조회 엔드포인트 등록)은 admin 만 |
| 플랫폼 관리자 | 테넌트 목록과 기능 자격만. **통화·고객·녹취 같은 업무 데이터는 볼 수 없다** |

## 2. 상담원 — 데스크톱 앱 "PBX 상담원"

### 2.1 설치와 첫 실행

1. 관리자에게 받은 주소에서 `KAsterAgent-Setup.exe` 를 받는다. 이 주소는 로그인 없이 열린다.
2. 실행한다. 관리자 권한을 묻지 않는다. 설치 위치를 묻지 않는다 (이미 깔린 자리가 있으면 그 자리에 덮어쓴다).
3. 처음 실행하면 로그인 화면이 뜬다. 오른쪽 아래 **서버 설정**을 눌러 서버 주소(`https://<API 도메인>`)를 넣고 저장한다.

> 설치 파일이 **서명되어 있지 않다**(2026-09-03 기준). Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행"으로 넘어간다. 관리자가 배포한 파일인지 확인한 뒤에만 그렇게 한다.

### 2.2 로그인

| 항목 | 설명 |
|---|---|
| 아이디 · 비밀번호 | 관리자가 상담원 설정에서 만든 계정 |
| 내선 | 이 자리의 내선 번호 |
| 이 PC 에서 소프트폰으로 통화 | 켜면 이 앱이 전화기가 된다. 끄면 책상 전화기 자리로 동작한다 (2.3) |
| 아이디·내선 저장 | 다음 로그인 때 아이디와 내선을 채워 둔다 |
| 자동 로그인 | 다음 실행 때 묻지 않고 접속한다. **비밀번호는 저장하지 않는다** — 토큰을 Windows 계정 보호 저장소(DPAPI)에 둔다 |

로그인이 되면 "이전 로그인으로 접속 중…" 을 거쳐 대기 화면이 뜬다. 같은 PC 에 두 사람이 앉으면 앱을 두 개 띄울 수 있다 (프로필이 갈린다).

### 2.3 책상 전화기(실기기) 자리

"이 PC 에서 소프트폰으로 통화"를 끄고 들어오면 대기 화면에 **"전화기에 아래 값을 넣으세요"** 가 뜬다.

| 표시 | 전화기에 넣을 곳 |
|---|---|
| 서버 | SIP 서버 주소 (`<PBX 주소>:<SIP 포트>`, 기본 포트 48950) |
| 계정 | SIP 사용자 이름 (보통 내선 번호) |
| 도메인 | SIP 도메인 |
| 전송 | UDP |
| 비밀번호 | 이 자리의 SIP 비밀번호 |

전화기에 넣고 **다시 확인**을 누른다. 전화기 표시등이 초록이 되면 끝이다. 전화기가 등록될 때까지 전화는 오지 않는다.

### 2.4 대기 화면

| 구역 | 내용 |
|---|---|
| 신원 막대 | 상담원 이름, 내선, 서버 · 전화기 · 근무 상태 표시등 |
| 당겨받을 수 있는 전화 | 큐에서 기다리는 전화 목록. 목록/타일 보기. 누르면 당겨받는다 (2.10) |
| 전화 걸기 | 발신번호 선택 + 번호 입력 + 걸기 (2.9) |
| 아래 버튼 | 업데이트 있음 · 지난 통화 · 설정 · 로그아웃 |

표시등 색이 빨강이면 2.15 로 간다.

### 2.5 근무 상태 바꾸기

신원 막대의 근무 상태를 눌러 **대기 ↔ 이석(휴식·식사·교육·일시정지)** 을 고른다.
대기가 아니면 전화가 배정되지 않는다. 통화 중에 바꾸면 통화가 끝난 뒤 적용된다.

- 창을 닫기(X) 하면 기본 설정에서는 **트레이로 내려가고 일시정지**가 된다. 앱을 아주 끄려면 트레이 아이콘에서 종료한다.
- 앱을 끄거나 PC 를 끄면 서버가 접속 끊김을 알아채고 **그 자리로 전화를 보내지 않는다.** 다시 켜면 풀린다.

### 2.6 전화 받기

전화가 오는 방식은 사이트의 분배룰 설정에 따라 둘 중 하나다.

**A. 제안 화면 (수락 대기시간이 설정된 큐)**
"받으시겠습니까?" 와 남은 시간이 뜬다. **수락**하면 전화기가 울리고, **거절**하거나 시간이 지나면 다음 상담원에게 간다.
여러 상담원에게 동시에 물을 수 있다. 먼저 수락한 사람이 받고, 나머지 화면의 제안은 바로 사라진다.
이 화면에는 자동 받기가 걸리지 않는다.

**B. 바로 벨 울림**
**받기 / 끊기** 버튼이 뜬다. 창이 다른 창 뒤에 있어도 알림이 뜬다 (트레이 알림 + 벨소리).

자동 받기: 설정 > 통화 > "자동 받기(초)" 를 0 보다 크게 두면 그 시간 동안 울린 전화를 스스로 받는다. 제안 화면에는 적용되지 않는다.

### 2.7 통화 중

| 버튼/영역 | 동작 |
|---|---|
| 상단 | 어느 지사·DID 로 걸려온 전화인지, 상대 번호, 고객 이름, 통화 시간 |
| 메모 | 적으면 통화가 끝날 때 저장된다 |
| 키패드 | ARS 등에 번호를 보낸다 (DTMF). 책상 전화기 자리도 여기서 누를 수 있다 |
| 마이크 | 핫키 또는 버튼으로 끈다. 화면의 표시가 실제 상태다 — 눌렀는데 표시가 안 바뀌면 적용되지 않은 것이다 |
| 보류 | 사이트가 보류 기능코드를 설정한 경우에만 보인다. PBX 응답을 "PBX 응답 대기(초)" 만큼 기다린다 |
| 돌려주기 | 상대를 고르는 창이 뜬다 (아래) |
| 고객 정보 | 상대 번호로 찾은 고객 정보 창을 연다 |
| 끊기 | |

**돌려주기 (전환)**
"누구에게 돌려줄까요?" 창에서 이름이나 내선을 입력해 좁힌다. 상대가 **지금 받을 수 있는지**(대기 상태인지)가 표시된다. 받을 수 없는 상대에게는 돌려지지 않는다.
- **협의** 를 켜면 먼저 상대와 통화한 뒤 넘긴다. 협의 중 **취소**하면 원래 통화로 돌아온다.
- 협의를 끄면 바로 넘긴다.
- 설정 > 전환 에 자리를 적어 두면 통화 중 **숫자 키 1~9** 로 바로 넘긴다. 번호를 적고 있는 칸에서는 먹지 않는다.

### 2.8 통화 후

통화가 끝나면 **후처리** 상태가 된다. 메모를 마저 적고 저장한다.
설정 > 통화 > "후처리 뒤 자동 대기(초)" 를 두면 그 시간 뒤 스스로 대기로 돌아간다. 0 이면 직접 바꿔야 한다.

### 2.9 전화 걸기

1. 대기 화면 전화 걸기에서 **발신번호**를 고른다. 관리자가 허용한 번호만 나온다. "설정된 발신번호 없음" 이면 관리자에게 요청한다.
2. 번호를 넣고 **걸기**.
3. 내선인지 외부 번호인지는 자릿수가 아니라 **등록된 내선 목록에 있는지**로 가른다.
4. 소프트폰 자리는 "자동응답 대기(초)" 안에 걸려 오는 전화를 **내가 건 전화**로 보고 스스로 받는다. 책상 전화기 자리는 "전화기를 받으면 연결됩니다" 가 뜨고, 수화기를 들면 상대에게 연결된다.

> 자동응답 대기를 길게 잡으면 그 사이 걸려 온 고객 전화까지 자동으로 받는다. 기본값을 유지한다.

### 2.10 당겨받기

대기 화면의 "당겨받을 수 있는 전화" 에서 누르면 내가 받는다. 같은 전화를 두 사람이 동시에 누르면 **2초 안에 먼저 누른 사람**만 받고 나머지는 거절된다.
책상 전화기에서는 기능코드(기본 `*8`)를 누른다. 같은 대리응답 그룹 안에서만 된다.

### 2.11 정보 창

대기·통화 화면에서 옆 창으로 연다. 읽기 전용이다.

| 창 | 내용 |
|---|---|
| 상담원 목록 | 상담원별 근무 상태. 이름·내선으로 좁힌다 |
| 큐 현황 | 큐별 대기 수, 최대 대기 시간 |
| 공지 | 관리자가 올린 공지. 새 공지는 알림으로도 온다 |
| 고객 정보 | 통화 상대의 고객 정보 |
| 지난 통화 | 내가 받은/건 통화 이력 |

### 2.12 설정

| 탭 | 항목 | 설명 |
|---|---|---|
| 서버 | 서버 주소 | `https://<API 도메인>`. 바꾸면 다시 로그인한다 |
| 서버 | 웹 연동 · 링크 다시 등록 | 웹 상담 화면에서 이 앱을 부르는 링크(`kastercti://`)의 등록 상태. 안 되면 다시 등록 |
| 오디오 | 마이크 · 통화 소리 · 벨소리 | 장치 선택. **바꾼 장치는 다음 통화부터** 쓰인다 |
| 핫키 | 받기 · 끊기 · 마이크 | 창이 뒤에 있어도 먹는다. Ctrl·Shift·Alt 중 하나를 넣어야 한다. 예 `Ctrl+Shift+F9` |
| 전환 | 1~9 자리 (이름 · 대상 · 협의) | 통화 중 숫자 키 전환 대상 |
| 통화 | 자동응답 대기(초) | 2.9 |
| 통화 | PBX 응답 대기(초) | 보류·협의 전환 응답 대기. 짧으면 멀쩡한 보류에도 "응답 없음"이 뜬다 |
| 통화 | 자동 받기 · 자동 끊기 · 후처리 뒤 자동 대기 (초) | 0 이면 쓰지 않는다 |
| 일반 | 색 테마 | 시스템 따르기 / 밝게 / 어둡게 |
| 일반 | 윈도우에 로그인하면 함께 시작 | 자리마다 따로 등록된다 |
| 일반 | 다른 창 위에 늘 보이기 · 닫기를 누르면 트레이로 내리기 | |
| 일반 | 벨소리 | 무음으로 두면 화면과 트레이 알림만 남는다 |
| 앱 | 버전 · 지금 확인 · 설치 파일 받기 · 받은 폴더 열기 | 2.13 |
| 앱 | 문제 기록 · 로그 폴더 열기 | 2.15 |

### 2.13 업데이트

대기 화면에 **업데이트 있음** 이 뜨거나 설정 > 앱 에서 **지금 확인**을 누른다.
**설치 파일 받기** → 받은 파일의 지문을 앱이 검증한다 → **통화가 없을 때** 받은 파일을 실행한다. 실행 중인 앱은 설치 프로그램이 닫는다.
설치는 상담원이 정한다. 관리자가 "필수"로 표시한 버전은 안내가 계속 뜬다.

### 2.14 웹 상담 화면에서 넘어오기

웹 상담 화면(3장)에서 "데스크톱 앱으로 넘기기"를 누르면 이 앱이 열리고 같은 계정으로 접속된다.
앱에 설정된 서버 주소와 웹이 넘긴 서버 주소가 다르면 받지 않는다. 한 PC 에 앱이 둘이면 나중에 뜬 쪽은 웹 연동만 안 될 뿐 통화는 된다.

### 2.15 문제가 생겼을 때

| 증상 | 먼저 볼 것 |
|---|---|
| 전화기 표시등 빨강 (소프트폰) | 설정 > 오디오 장치, 서버 주소, 네트워크. 로그 폴더의 "못 켠 사유" 줄 |
| 전화기 표시등 빨강 (책상 전화기) | 전화기에 넣은 서버·계정·비밀번호. 다시 확인 |
| 서버 표시등 빨강 | 네트워크. 앱이 스스로 재접속한다. 오래 가면 관리자에게 |
| 전화가 안 온다 | 근무 상태가 대기인지, 트레이로 내려가 있지 않은지, 전화기 표시등이 초록인지 |
| 소리가 안 들린다 / 상대가 못 듣는다 | 설정 > 오디오. 장치가 **목록에 있다고 그 자리에 꽂혀 있는 것은 아니다** |
| 상대에게 내 목소리가 안 간다 (등록은 됨) | 관리자에게 — 라우터 NAT 문제일 수 있다 (관리자 매뉴얼 7.2) |
| 눌렀는데 마이크 표시가 안 바뀐다 | 적용되지 않은 것이다. 다시 누른다 |
| 업데이트 파일 받기가 404 | 관리자에게 — 서버 쪽 파일 배치 문제 |

문제를 보고할 때는 설정 > 앱 > **로그 폴더 열기** 로 연 폴더의 최근 파일을 함께 보낸다.

## 3. 상담원 — 웹 앱

브라우저에서 쓰는 상담 화면이다. **통화 자체(소리)는 하지 않는다.** 책상 전화기나 데스크톱 앱이 통화하고, 이 화면은 상태를 보고 제어한다.

### 3.1 접속과 로그인

`https://<상담원 도메인>` 에서 로그인 ID · 내선 번호 · 비밀번호를 넣는다.
**통화 방식** 은 둘 중 하나다.

| 선택 | 뜻 |
|---|---|
| 소프트폰 사용 | 데스크톱 앱과 연동한다. 로그인 뒤 데스크톱 앱으로 넘길 수 있다 (2.14) |
| SIP Phone 사용 | 책상 전화기 자리. 이 화면은 제어와 메모만 한다 |

### 3.2 화면

**Full 모드** (기본)

| 구역 | 내용 |
|---|---|
| 상단 바 | 이름 · 내선 · **상태 변경** · 미니 모드 · 로그아웃 |
| 왼쪽 | 메뉴, 활성 통화 목록 |
| 가운데 | 현재 통화 카드 (진행 중인 통화 없음 / 통화 정보 · 제어 버튼) |
| 오른쪽 | 처리 결과 · 전환 내선 · 상담 메모 · 태그 (VIP, 콜백, 민원, 전환…) |
| 아래·옆 패널 | 큐 상태 (대기 · 최대 대기) · 공지사항 · 최근 이력 · 이벤트 기록 · 오늘 KPI |

**미니 모드** — 상단 바의 미니 모드 버튼 또는 주소에 `?mode=mini`. 420px 카드 하나에 현재 통화와 제어만 남는다. 다른 업무 화면 옆에 붙여 둘 때 쓴다.

### 3.3 할 수 있는 일

| 동작 | 어디서 | 비고 |
|---|---|---|
| 상태 변경 | 상단 바 | 1.3 근무 상태 |
| 전화 걸기 | 전화 발신 팝업 (발신번호 · 대상 번호) | 발신번호는 관리자가 허용한 것만 |
| 당겨받기 | 활성 통화 목록의 대기 중 통화 | 2초 규칙 |
| 끊기 · 마이크 · 보류 | 통화 제어 팝업 | 보류는 사이트가 기능코드를 설정한 경우에만 활성 |
| 전환 | 통화 제어 팝업 (전환 방식 · 전환 내선 · 상담원 검색) | 협의 전환은 완료/취소 버튼이 따로 있다 |
| 메모 저장 | 오른쪽 패널 | 처리 결과 9종: 주문 완료 · 후속 조치 필요 · 콜백 예약 · 판매 완료 · 관심 없음 · 불만 접수 · 기술 이슈 · 단순 문의 · 기타 |

버튼을 누른 직후의 표시는 "요청 접수"다. **최종 상태는 서버가 PBX 이벤트를 받아 바꾼다.** 몇 초 뒤에도 안 바뀌면 실패한 것이다.

### 3.4 데스크톱 앱으로 넘기기

로그인 뒤 안내에 따라 넘기면 브라우저가 `kastercti://` 링크로 데스크톱 앱을 연다. 앱이 없으면 설치 안내가 뜬다. 앱이 켜져 있으면 연결 결과를 이 화면이 확인해 보여 준다.

## 5. 관리자 — 운영 설정

### 5.0 설정이 PBX 에 반영되는 원리

비유하면 관리자 콘솔은 **설계도**를 고치는 곳이고, PBX 설정 메뉴의 "적용"이 설계도를 **교환대에 배선**하는 순간이다. 설계도만 고치면 전화는 그대로다.

1. 관리자 콘솔에서 저장한 값은 DB 에 들어간다.
2. `PBX 설정` 메뉴의 **.conf 미리보기 / dry-run** 이 DB 값으로 설정 파일 7개(`pjsip.conf`, `rtp.conf`, `extensions_inbound/queue/agent.conf`, `queues.conf`, 대기음)를 만들어 검증하고, 지금 PBX 에 있는 파일과의 **차이**를 보여 준다.
3. **변경 내역을 본 뒤에만** 적용 버튼이 열린다. 적용하면 파일을 쓰고 PBX 에 reload 명령(PJSIP · dialplan · queue · 대기음)을 보낸다.
4. 다음은 자동으로 막힌다: 다른 사이트가 소유한 PBX 디렉터리(owner marker 불일치), 내선이 사라지는 렌더, DID 가 아무 데도 안 걸리는 렌더, 직전 적용본 대비 급격히 줄어든 렌더.

주의할 것 세 가지.

- **SIP 등록 포트 변경은 reload 로 반영되지 않는다.** PBX 프로세스 재시작이 필요하다 (설치 매뉴얼 9장).
- **호 분배룰 변경은 저장 즉시** `queues.conf` 를 다시 쓰고 reload 한다. 다른 메뉴는 PBX 설정에서 적용해야 한다.
- 실제 라우팅의 진실은 **렌더된 dialplan** 이다. DB 화면과 다르게 동작하면 미리보기의 diff 를 본다.

### 5.1 지사 관리

| 항목 | 설명 |
|---|---|
| 인입 DID | 이 지사로 들어오는 번호 |
| 사용할 멘트 · 사용할 호 분배룰 | 지사 기본 |
| 소속 상담원 | |
| 지사 기본 발신번호 | 상담원이 고를 발신번호의 기본 |
| 적용할 착신전환 규칙 · 작동 조건 · 요일 · 시작/종료 시간 | 지사 단위 시간표 |
| CID / SMDR | 타사 CID 프로그램(로지 · 아이콘 · 콜마너) 연동 값 |
| 상담원 발신번호 인증 | 지사 × 상담원별 허용 발신번호 |

### 5.2 상담원 설정

| 항목 | 설명 |
|---|---|
| 로그인 ID · 이름 · 비밀번호 | 비밀번호 초기화 버튼이 따로 있다 |
| 내선 · 내선 표시명 | 표시명은 상대 전화기에 뜨는 이름 |
| 역할 | agent / supervisor / admin |
| 기본 큐 | |
| 내선 잠금 | 잠금 없음 / 국선 발신 잠금 / 전체 잠금 |
| 발신 카테고리 권한 | 국내 · 대표번호(15xx/16xx/18xx) · 유료(060) · 국제 · 전화기 직접 발신 |
| SIP 비밀번호 | 비우면 시스템 설정의 사이트 기본 SIP 비밀번호를 쓴다. **저장할 때 비워지지 않는다** |

### 5.3 상담원 그룹

그룹을 만들고 상담원을 넣는다. 호 분배룰 멤버로 그룹을 넣으면 그룹 변경이 분배룰에 따라간다.

### 5.4 호 분배룰 설정

| 항목 | 설명 |
|---|---|
| Rule명 · 사용 | |
| 외부 착신 방식 | 순차 착신(순위) / 분배 착신(전략) / 무조건 착신(대상 유형: 상담원 · 호 분배룰 · 외부번호) |
| 분배 전략 (고급) | PBX 전략. 기본은 가장 오래 쉰 상담원 |
| 링 타임아웃(초) · 최대 대기시간(초) · 후처리 시간(초) | |
| 수락 대기시간(초) | 제안 화면(2.6 A)을 띄우는 시간. 0 이면 바로 벨 |
| Auto Pause | 못 받은 상담원을 자동으로 뺀다 |
| 오버플로 규칙 | 대기 시간(초) 초과 시 대상 유형(호 분배룰 · 외부번호 등)으로 보낸다 |
| 멤버 | 상담원 · 상담원 그룹, 순위/페널티 |

저장 즉시 PBX 에 반영된다 (5.0).

### 5.5 착신전환 설정

대상 DID → 전환 방식(외부번호 · 내선 · 호 분배룰) → 착신 조건(즉시 · 대기시간 초과 · 상담원 없음) → 적용 방식(항상 / 요일·시간 지정) → 대기 시간 · 재착신 유지 · 활성.

### 5.6 공휴일 설정

전체 또는 지사별로 날짜형 · 매년 반복 · 영업일 예외 규칙을 둔다. 공휴일이 시간표보다 먼저 적용된다.

### 5.7 아웃바운드 발신번호

발신번호 규칙을 만들고 **테스트** 버튼으로 "이 상담원이 이 번호로 걸면 어떤 발신번호가 나가는가"를 확인한다.

### 5.8 공유규칙 (호 분배)

분배룰 공통 정책의 오버라이드.

### 5.9 멘트 관리

| 항목 | 설명 |
|---|---|
| 멘트명 · 파일명 · 분류 · 문구 · 설명 · 프롬프트 키 | |
| 파일 업로드 | 8kHz 16bit 모노 WAV 가 안전하다 |
| TTS 생성 | 문구로 음성을 만든다. 서버에 TTS 제공자가 설정된 사이트만 |
| 활성 | |

저장한 파일은 PBX 음원 디렉터리(`custom/`)에 놓인다. dialplan 이 그 파일을 가리키므로 파일명을 바꾸면 PBX 설정을 다시 적용한다.

### 5.10 문자 템플릿 · 상담분류

- 문자 템플릿: 템플릿 이름 · 코드 · 카테고리 · 문자 내용 · 활성. ARS 의 문자 발송 노드와 수신거부 안내가 쓴다.
- 상담분류: AI 분석이 통화를 분류할 때 쓰는 목록. `call-analysis` 자격이 켜진 사이트만 메뉴가 보인다.

### 5.11 ARS 플로우 빌더

`ars-flow-builder` 자격이 켜진 사이트만 보인다. 기존 IVR 메뉴(PBX 설정 > IVR 메뉴)는 그대로 쓸 수 있고, 다단계 시나리오가 필요할 때 이것을 쓴다.

1. 플로우를 만들고 캔버스에서 노드를 잇는다. 노드: 안내 재생 · 메뉴(입력 대기 · 재시도 횟수) · 번호 입력받기(최소/최대 자릿수) · 조건(요일 · 시작/끝 시각) · 호 분배룰 연결 · 전환 번호 · 문자 발송(템플릿 ID · 받는 번호) · 수신거부 · 외부 조회(조회할 엔드포인트 · 조회 중 안내, `ars-http-lookup` 자격 필요) · 종료 안내.
2. **저장할 때 검증**한다. 통화가 갇히는 그래프(끝이 없는 순환)는 저장이 거부된다.
3. 미리보기에서 컴파일된 dialplan 을 그대로 본다.
4. DID 에 플로우를 건다 (플로우 선택). 플로우를 지우면 그 DID 는 표준 경로로 돌아간다.
5. PBX 설정에서 적용한다 (5.0).

기존 IVR 메뉴를 **가져오기**로 플로우로 바꿀 수 있다. Smart ARS 와 수신거부 설정은 가져오지 않는다 (동작이 달라지기 때문 — 8장).

### 5.13 공지사항

제목 · 내용 · 중요도 · 상단 고정 · 노출 시작/종료 · 대상 · 로그인 표시. 저장하면 상담원 앱에 즉시 푸시된다.

### 5.14 DID / 내선

DID · 내선 · 분배룰 번호 · 기능코드를 한 표에서 보고 **충돌**을 표시한다. "설정 열기"로 해당 화면에 간다. 번호 체계를 한 번에 바꾸는 기능은 일부러 두지 않았다.

### 5.15 연동

| 유형 | 값 |
|---|---|
| VIX_PHONE / VIX_SMS | VIX Host · Port · Route/Action · 계정 |
| WEBHOOK | URL · Auth Token · Secret · Custom Headers |
| SLACK_WEBHOOK | URL |

ARS 외부 조회 엔드포인트(HTTP_LOOKUP)는 별도 메뉴이며 **admin 역할만 등록**할 수 있다. 자격증명은 암호화 저장되고, 사설망 주소로의 조회는 서버가 거부한다(SSRF 가드).

### 5.18 패킷 캡처

시스템 > 패킷 캡처. 서버 env(`PACKET_CAPTURE_ENABLED`)와 사이트 자격(`packet-capture`)이 **둘 다** 켜져 있어야 시작된다.
캡처 파일에는 **통화 음성(RTP)** 이 들어간다. 녹취 암호화가 꺼져 있으면 평문으로 남는다 — 화면이 이 상태를 표시한다. 다운로드는 감사 기록에 남고 7일(기본) 뒤 지워진다.

### 5.19 고객 관리 · 수신거부 · 블랙리스트

| 메뉴 | 항목 |
|---|---|
| 고객 관리 | 성명 · 등급 · 대표 전화번호 · 추가 전화번호 · 지사 · 기본 메모 · 최종 통화일. 상세 드로어에서 바로 고친다 |
| 수신거부 고객 관리 | 080 수신거부 · ARS 수신거부로 등록된 번호와 사유. 출처(즉시 / DTMF / 스마트 / ARS 플로우)별로 기록된다 |
| 블랙리스트 관리 | 번호 또는 패턴 · 매칭 방식 · 사유. 가져오기 지원. 인바운드 dialplan 첫 단계에서 차단된다 |

### 5.20 자주 쓰는 설정 흐름

1. **DID 를 ARS 로**: IVR 메뉴 만들기 → DID 연결 방식 "IVR 메뉴 연결" → 지사에 DID 연결 → PBX 설정 적용 → 대표 DID 로 걸어 확인.
2. **DID 를 특정 상담원에게 직결**: 상담원 내선 활성 확인 → DID 연결 방식 "내선 직결" + 직접 착신 내선 → 적용.
3. **큐 방식 바꾸기**: 호 분배룰에서 외부 착신 방식 · 멤버 · 타임아웃 조정 → 저장(즉시 반영).
4. **시간대별 착신전환**: 착신전환 규칙에서 적용 방식 "요일/시간 지정" + 시간표 → 공휴일은 공휴일 설정 → 적용.
5. **국선 여러 개**: 트렁크 등록 → 국선 그룹에 멤버 · 우선순위 → 기본 발신 그룹 켜기 → 미리보기에서 발신 경로 확인 → 적용 → 주 회선 장애 우회를 실제로 검증.
6. **상담원 새로 앉히기**: 상담원 설정 등록 → 큐 멤버 추가 → 지사 소속 · 발신번호 → 데스크톱 앱 설치와 로그인 (2장) → 내선 SIP 탭에서 등록 확인.
7. **번호 충돌 찾기**: DID / 내선 메뉴에서 충돌 표시 → 설정 열기.

## 6. 플랫폼 관리자

사이트(테넌트)마다 어떤 기능을 열지 정하는 별도 계층이다. 관리자 콘솔의 `/platform/login` 으로 들어가며, 상담원·관리자 계정과 **다른 계정**이고 다른 브라우저 저장소 키를 쓴다 (관리자 콘솔과 서로 로그아웃시키지 않는다).

### 6.1 첫 계정

서버 env `PLATFORM_ADMIN_BOOTSTRAP_LOGIN` / `_PASSWORD` 로 **플랫폼 관리자가 0명일 때만** 첫 계정이 만들어진다. 이 비밀번호는 1회용이다 — 첫 로그인에서 **반드시 변경**해야 다른 화면이 열린다. 이후 계정은 "플랫폼 관리자 등록"(로그인 ID · 이름 · 초기 비밀번호)으로 만든다.

### 6.2 기능 자격

테넌트 목록 → 테넌트 선택 → 기능별 활성/비활성.

| 기능 키 | 이름 | 기본값 | 켜면 열리는 것 | 주의 |
|---|---|---|---|---|
| `call-analysis` | 통화 AI 분석 | 꺼짐 | 통화 이력의 AI 분석 드로어, 상담분류 관리 메뉴 | 서버 env `CALL_ANALYSIS_ENABLED=true` 와 STT/LLM 제공자가 함께 있어야 실제로 돈다 |
| `ai-insights` | AI 인사이트 대시보드 | 꺼짐 | 추이 분석의 AI 탭 | `call-analysis` 결과를 쓴다 |
| `ars-flow-builder` | ARS 플로우 빌더 | 꺼짐 | ARS 플로우 빌더 메뉴 | |
| `ars-http-lookup` | ARS 외부 조회 | 꺼짐 | 외부 조회 엔드포인트 등록과 플로우의 외부 조회 노드 | PBX 망에서 바깥으로 HTTP 가 나간다. env `ARS_HTTP_LOOKUP_ENABLED` 가 최종 거부권 |
| `recording-encryption` | 녹취 암호화 | 꺼짐 | 새 녹취를 AES-256-GCM 으로 암호화 | **한 번 켜면 되돌릴 수 없다.** 켜기 전에 확인 대화상자가 뜨고, 켠 뒤에는 잠긴다. 암호화 키(`RECORDING_ENCRYPTION_KEY`)를 잃으면 녹취를 영원히 못 듣는다 |
| `packet-capture` | 패킷 캡처 | **켜짐** | 패킷 캡처 메뉴 | 서버 env 도 켜져 있어야 동작 |

자격 변경은 **변경 이력**에 누가 언제 무엇을 바꿨는지 남는다. 멀티노드 서버에서는 반영까지 최대 30초 걸린다.

플랫폼 관리자는 **테넌트를 만들지 못한다** (목록만). 테넌트 생성은 설치 매뉴얼 7장의 절차를 따른다.

## 7. 일상 운영 점검과 1차 대응

### 7.1 매일 아침 5분

| 순서 | 어디서 | 정상 |
|---|---|---|
| 1 | 대시보드 경보 패널 | 경보 없음 |
| 2 | 시스템 모니터링 | DB · Redis · PBX 초록, 운영 모드 "정상", 발행 대기 0 근처 |
| 3 | PBX 설정 > 내선 SIP | 출근한 자리의 내선이 등록됨 |
| 4 | 시스템 설정 > 시간 동기화 | 편차 수 초 이내 |
| 5 | 보고서 > 녹취 목록 | 어제 통화에 녹취가 붙어 있음 |

### 7.2 증상별 1차 대응

| 증상 | 원인 후보 | 확인 · 조치 |
|---|---|---|
| 특정 상담원에게 전화가 안 간다 | 근무 상태 이석 / 앱 접속 끊김(자동 pause) / 내선 미등록 / 큐 멤버 아님 | 상담원 현황 → 내선 SIP 탭 → 분배룰 멤버 |
| 등록은 됐는데 벨이 안 울린다 / 한쪽 소리가 없다 | 상담원 쪽 라우터가 UDP 핀홀을 닫음 | PBX 설정 적용본에 `qualify_frequency=30` 이 있는지(기본 렌더에 포함). 그래도 안 되면 시스템 > 패킷 캡처로 SIP/RTP 를 잡아 본다 |
| 전화기가 403 으로 등록 거부 | 죽은 등록이 남아 있음 | 렌더 기본값 `remove_existing=yes` 가 적용됐는지 → PBX 설정 재적용 |
| 관리자 콘솔이 "Network Error" | 프런트 번들에 개발용 API 주소가 박힘 | 설치 매뉴얼 6장의 빌드 검증 절차로 다시 만든다 |
| PBX 설정 적용이 거부된다 | owner marker 불일치 / 렌더 가드 | 오류 문구를 그대로 읽는다. marker 는 설치 매뉴얼 4장 |
| SIP 포트를 바꿨는데 전화기가 옛 포트로만 붙는다 | reload 로는 포트가 안 바뀜 | PBX 프로세스 재시작 (설치 매뉴얼 9장) |
| 통화가 끝났는데 화면에 10분 넘게 남아 있다 | PBX 이벤트 유실 | 10분 뒤 복구 스위퍼가 `RECOVERY_TIMEOUT` 으로 닫는다. 자주 나면 호 로그를 본다 |
| 데스크톱 업데이트 "설치 파일 받기"가 404 | 서버 컨테이너가 설치 파일 경로를 못 본다 | 설치 매뉴얼 8장의 마운트 확인 |
| 시스템 모니터링에 "제한 운전" | DB 장애 30초 초과 | DB 를 복구하면 스스로 정상으로 돌아온다. 그동안 이벤트는 스풀에 쌓인다 |
| 타사 CID 프로그램에 통화 정보가 안 온다 | 포트(28002 로지 · 28003 아이콘 · 28004 콜마너)가 안 열림 | 방화벽. 세 프로그램은 포맷 규칙이 다르니 한 쪽만 고치지 않는다 |

### 7.3 무엇이 어디에 기록되는가

| 기록 | 위치 |
|---|---|
| 녹취 재생·다운로드 | 감사 기록 (녹취 접근) |
| 패킷 캡처 다운로드 | 감사 기록 (패킷 캡처) |
| 데스크톱 업데이트 결과 | 감사 기록 (업데이트) |
| 기능 자격 변경 | 플랫폼 > 변경 이력 |
| DB 장애 복구 | 감사 기록 (복구) |
| PBX 원본 이벤트 | 보고서 > 호 로그 |
| 상담원 앱 문제 | 상담원 PC 의 로그 폴더 (2.15) |

**없는 것**: 로그인 감사(마지막 로그인 시각만 남는다), 조회 감사, 통합 감사 화면.

## 8. 설계와 다르게 동작하는 것 · 아직 없는 것 (인수인계용)

검수 때 "요구한 기능이 없다"는 오해가 가장 많이 나는 항목이다. 근거는 [갭 분석](../design/2026-09-03-design-vs-implementation-gap-analysis.md).

### 8.1 이름·형태가 다른 것

| 요구서 표현 | 실제 | 어디서 |
|---|---|---|
| 내선 잠금 | 상담원 발신 제한 정책 | 상담원 설정 > 내선 잠금 |
| 내선 서비스 등급 (국제/시외/시내/구내) | 발신 카테고리 권한 (국내/대표번호/유료/국제). **시외·시내는 구분하지 않는다** | 상담원 설정 |
| 내선그룹 | 상담원 그룹 | 상담원 그룹 |
| 가상버퍼 번호 | 번호를 주지 않는다. 큐 대기 상태로 표시 | 큐 현황 |
| ARS 번호 · 국선 번호 | 별도 번호 자원이 아니다. DID + IVR/플로우, 트렁크 표시번호 | PBX 설정 |
| 시스템 날짜/시간 변경 | 조회 + 편차 감시만 | 시스템 설정 |
| 시스템 시간변수 | 기능별 개별 타이머 | 분배룰 · 착신전환 · 오버플로 |
| 전화기 응답모드 (Auto Answer) | 데스크톱 앱의 자동 받기(초) — 소프트폰 정책 | 데스크톱 설정 > 통화 |
| TAPI 대체 (open TSP) | REST + WebSocket 외부 CTI API. **Windows TAPI 앱과 직접 호환되지 않는다** | `design/2026-08-07-external-cti-api-guide.md` |
| WebSocket `/ws/agent` · `/ws/admin` | 네임스페이스 하나 `/ws` | — |
| 녹취 화자분리 | 스테레오 좌/우 채널 분리. 모노 녹취는 화자를 못 가른다 | 시스템 설정 > 녹취 채널 방식 |

### 8.2 없는 것

| 항목 | 상태 |
|---|---|
| 실시간 감청 | 정책상 지원하지 않는다 |
| 콜백 접수 메뉴 · 재콜 목록 | 없음. 대기 초과는 오버플로 규칙으로 |
| 상태 전환 이유 코드 입력 | 없음 |
| 통화 이력·고객 화면의 번호 마스킹 | 없음 (AI 전사문에만) |
| MFA · 관리자 IP 허용목록 · 통합 감사로그 · 민감필드 암호화 | 없음 |
| 콜마너/올플릿 배차 API | 없음 (설계만) |
| 단말 키버튼 지정 | PBX 계층에서 불가능 (단말 프로비저닝 영역) |
| 시스템 재시동 · 포트 초기화 버튼 | 없음. 운영 절차로 |
| 개인 단축다이얼 | 없음. 공용 단축 발신만 |
| 큐 단건 상세 화면 | 없음 |
| 상담원 데스크톱 CI · 코드 서명 | 없음 |

### 8.3 아직 실 PBX 에서 확인하지 않은 것

에코 · 큐 오버플로 외부 전환 · 녹취 암호화 후 재생 · ARS 플로우와 외부 조회 실통화 · AI 분석 실녹취. 이 기능을 처음 켤 때는 검증용 DID 로 먼저 건다.
