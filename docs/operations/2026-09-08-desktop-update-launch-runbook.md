# PBX 상담원 1.0.3 업데이트 화면 및 설치 실행

- ‘업데이트 있음’과 필수 업데이트 안내를 누르면 설정의 **업데이트** 탭을 바로 연다. 설정창이 이미 열려 있어도 해당 탭으로 전환하며 입력한 설정은 유지한다.
- **다운로드 및 설치**를 누르면 파일을 다운로드하고 SHA-256을 검증한다. 실행 직전에 다시 검증한 뒤 설치 프로그램을 실행한다.
- 설치 프로그램 시작에 성공한 경우 상담원 앱을 종료해 파일을 교체할 수 있게 한다. 설치 마법사는 사용자가 진행한다.
- 다운로드 중 전화가 걸려오면 설치를 보류한다. 통화를 마친 뒤 **설치 실행**을 누른다.
- 실행 실패 시 파일을 유지하여 재시도할 수 있다. 파일이 변경됐으면 실행하지 않고 재다운로드를 안내한다.
- 로그인 후 자동 확인, 6시간 주기 확인, 일반/필수 업데이트 정책은 유지한다.

Release 테스트 737개 통과. 자동 실행 요청, 통화 중 설치 보류, 실행 직전 파일 변경 차단, 실행 실패 재시도를 포함한다. WPF 업데이트 탭의 최초·반복 선택도 확인했다. 실제 상담원 PC 설치 마법사 실행은 이 검증에 포함하지 않았다.

산출물은 `apps/desktop-win/release/KAsterAgent-1.0.3-Setup.exe`와 `release.json`이다. 서명 인증서가 없어 미서명으로 생성한다. 이번 동작은 1.0.3부터 적용되므로 이전 버전에서 1.0.3으로 올라올 때는 기존 방식대로 다운로드한 설치 파일을 직접 실행한다.
