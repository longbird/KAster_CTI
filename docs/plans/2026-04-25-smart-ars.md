# Smart ARS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace branch ARS menu selection with branch-level Smart ARS configuration.

**Architecture:** Smart ARS is stored in `branches.settingsProfile.smartArs` and validated in `AdminService`. The admin branch settings modal edits the same JSON contract using existing prompt, queue, and SMS template option lists.

**Tech Stack:** NestJS, Prisma JSON fields, Jest, React, Ant Design, TypeScript.
