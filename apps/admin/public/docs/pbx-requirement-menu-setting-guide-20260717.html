3. 요구사항별 메뉴 매칭

No요구사항설정 메뉴설정 방법 요약현재 판단
1지사별 DID/ARS/착신 정책지사 관리, PBX 설정 > DID, PBX 설정 > IVR 메뉴, 착신전환 설정지사를 등록한 뒤 지사 상세에서 사용할 DID를 연결한다. DID는 IVR 메뉴, 호 분배룰, 내선 직결 중 하나로 연결한다. 시간/장애/대기 조건은 착신전환 규칙으로 분리한다.수용, 구현 완료
2ARS 번호 별도 관리 여부PBX 설정 > DID, PBX 설정 > IVR 메뉴ARS를 별도 번호로 등록하지 않는다. 고객이 전화하는 번호는 DID이며, DID의 연결 방식을 IVR 메뉴로 선택하고 IVR 메뉴에서 DTMF 키별 호 분배룰을 지정한다.별도 번호 관리 불필요
3가상버퍼 번호 할당 여부호 분배룰 설정, 큐 현황가상버퍼는 통화가 분배 전 대기하는 상태이므로 다이얼 가능한 번호로 만들지 않는다. 분배룰의 최대 대기시간, 링 타임아웃, 상담원 멤버 구성으로 운영한다.번호 할당 불필요
4국선번호 마지막 4자리 표시PBX 설정 > 트렁크, 시스템 설정트렁크 등록 시 표시번호를 입력한다. 별도 표시번호가 없으면 대표번호 또는 트렁크 번호의 마지막 4자리를 운영 표시값으로 제안한다.수용, 구현 완료
5외부 착신 방식호 분배룰 설정분배룰 추가/수정에서 외부 착신 방식을 선택한다. 순차 착신은 순위 기반, 분배 착신은 분배 전략 기반, 무조건 착신은 대상 유형과 대상 값을 함께 지정한다.수용, 구현 완료
6무조건 착신호 분배룰 설정외부 착신 방식을 무조건 착신으로 선택하고 대상 유형을 상담원, 호 분배룰, 외부번호 중 하나로 지정한다. 운영 PBX에서 실제 라우팅 결과를 검증한다.수용, 운영 검증 필요
7착신전환 조건 다양화착신전환 설정DID를 선택하고 전환 방식을 외부번호, 내선, 호 분배룰 중 하나로 지정한다. 착신 조건은 즉시, 대기시간 초과, 상담원 없음을 선택하고 필요 시 요일/시간표를 추가한다.수용, 구현 완료
8시간별 동작착신전환 설정, 공휴일 설정시간표가 필요한 DID는 착신전환 규칙의 적용 방식을 요일/시간 지정으로 설정한다. 휴일 예외는 공휴일 설정에서 전체 또는 지사별 규칙으로 등록한다.수용, 구현 완료
9공휴일 지정공휴일 설정전체 지사 또는 특정 지사를 선택하고 날짜형/매년 반복/영업일 예외 규칙을 등록한다. 휴일 라우팅은 착신전환 또는 DID 라우팅과 함께 검증한다.수용, 구현 완료
10시간 동기화시스템 설정시간 동기화 상태 카드에서 앱 서버와 PBX 기준 시간, 편차, 마지막 확인 시간을 본다. 시간 변경 기능이 아니라 동기화 상태 점검 기능으로 운영한다.수용, 구현 완료
11내선 표시명상담원 설정상담원 추가/수정에서 내선 표시명을 입력한다. 비어 있으면 상담원명 또는 기본 내선명이 표시될 수 있으므로 단말 표시가 중요한 내선은 명시한다.수용, 구현 완료
12내선 잠금상담원 설정상담원 추가/수정에서 내선 잠금 값을 선택한다. 잠금 없음, 국선 발신 잠금, 전체 잠금 성격으로 운영하며 보안/발신 제한 정책으로 본다.수용, 구현 완료
13전화기 응답 모드보류현재 관리자 설정 대상이 아니다. Ring 기본 운영을 전제로 하며 Auto Answer가 필요하면 단말/소프트폰 정책과 함께 별도 설계한다. 음성 방송 모드는 수용하지 않는다.조건부 보류
14내선 서비스 등급권한 관리, 상담원 설정, 아웃바운드 발신번호기존 PBX COS 표를 그대로 복제하지 않는다. 발신 제한은 내선 잠금/발신번호 권한으로, 화면 기능 권한은 권한 관리로 분리한다.부분 대체, 전체 복제 불필요
15대리응답그룹통화 현황 조회, 상담원 그룹, 호 분배룰 설정같은 상담원 그룹 또는 같은 분배룰 범위에서 대리응답을 허용한다. 별도 pickup group 관리가 꼭 필요한지는 운영 검증 후 결정한다.제한 수용
16내선 그룹 지정상담원 그룹, 호 분배룰 설정상담원 그룹을 만들고 상담원을 배정한다. 호 분배룰에서 그룹 또는 개별 상담원을 멤버로 추가한다. 기존 PBX 내선그룹은 상담원 그룹/분배룰로 대체한다.대체 수용
17통화 그룹별 발신/응답 허용아웃바운드 발신번호, 권한 관리발신 허용은 발신번호 정책과 지사/상담원 권한으로 처리한다. 응답 허용은 분배룰과 대리응답 범위로 제한한다. 별도 통화 그룹 매트릭스는 후순위다.후순위
18직통전화 - DID 직접 착신PBX 설정 > DIDDID 추가/수정에서 연결 방식을 내선 직결로 선택하고 직접 착신할 상담원 내선을 지정한다. 큐 대기나 부재 fallback이 필요하면 1인 분배룰 연결을 우선 검토한다.수용, 구현 완료
19직통전화 - 오프훅 자동 발신보류수화기를 들면 자동 발신되는 기능은 단말 지원과 현장 시나리오가 필요하다. 현재 CTI 필수 기능이 아니므로 DID 직접 착신/단축 발신과 분리한다.보류
20브랜치 그룹지사 관리, 통화 현황 조회CTI의 지사와 PBX의 브랜치 그룹은 의미가 다를 수 있다. 지사 묶음이면 지사 관리로, 오프훅 당겨받기이면 대리응답 기능으로 흡수한다.부분 흡수, 나머지 보류
21발신자번호 내선/국선별 등록아웃바운드 발신번호, PBX 설정 > 트렁크내선/국선별 CLI 슬롯을 모두 복제하지 않는다. 대표 발신번호, 지사/상담원 허용 발신번호, 트렁크 표시번호로 단순화한다.과다 스펙, 불필요
22국선 이름PBX 설정 > 트렁크트렁크의 표시명과 표시번호로 운영 식별한다. 별도 국선 이름 메뉴는 만들지 않는다.후순위 표시 기능
23국선 그룹PBX 설정 > 트렁크 > 국선 그룹트렁크를 먼저 등록한 뒤 국선 그룹을 만들고 멤버 트렁크와 우선순위를 지정한다. 기본 발신 그룹을 활성화하면 발신 경로 생성 시 그룹 멤버가 반영된다.부분 수용, 기본 그룹 구현
24다중 국선 장애 우회PBX 설정 > 트렁크 > 국선 그룹, 호 로그우선순위가 있는 국선 그룹을 구성하고 운영 PBX에서 주 회선 장애, 보조 회선 발신, 원복 동작을 검증한다. 자동 health 판단과 동적 제외/복귀는 추가 요구로 분리한다.선행 정리 및 운영 검증 필요
25지사별/사업자별 발신 라우팅지사 관리, 아웃바운드 발신번호, PBX 설정 > 트렁크현재는 기본 국선 그룹만 사용한다. 지사별 국선 그룹, 상담원 소속 지사, DID 기준, 목적지 번호대, 사업자별 요금 정책 중 어떤 기준으로 라우팅할지 확정해야 한다.요구 확인 필요
26내선별 단축 다이얼보류상담원 개인별 단축번호는 아직 제공하지 않는다. 개인별 필요성이 확인되면 상담원 설정 또는 별도 연락처 기능과 함께 설계한다.후순위
27공동 단축 다이얼 / 단축 발신PBX 설정 > 단축 발신단축번호와 대상번호를 등록한다. 단축번호는 내선/외부 발신 패턴과 충돌하지 않도록 *01, #01 형식을 권장한다.수용, 구현 완료
28시간 표시 방법보류단말 표시 옵션에 가까우므로 CTI 관리자 설정으로 제공하지 않는다. 운영자가 CTI에서 관리해야 하는 근거가 생기면 시스템 설정 하위로 검토한다.후순위
29키버튼/전화기 종류별 버튼보류PBX는 단말 버튼 위치, LED, 라벨을 직접 제어하지 않는다. 단말이 보낸 기능코드/DTMF/SIP 요청만 처리할 수 있으므로 단말 모델별 프로비저닝 정보가 필요하다.PBX 단독 구현 불가
30다이얼번호 변경DID / 내선전체 번호 체계 변경 UI는 제공하지 않는다. 번호 자원 화면에서 DID, 내선, 분배룰 번호, 기능코드 충돌을 확인하고 대상 설정 화면으로 이동한다.제한 수용
31번호 자원/기능 코드 분리DID / 내선DID/내선/분배룰 번호는 번호 자원으로 보고, 대리응답/단축 발신 같은 기능 접근 번호는 기능코드로 분리한다. 화면의 설정 열기로 대상 메뉴에 진입한다.수용, 구현 완료

4. 운영자가 자주 쓰는 설정 흐름

4.1 지사 DID가 ARS로 들어오게 설정

  1. PBX 설정 > IVR 메뉴에서 안내 멘트, 메뉴 멘트, 키 입력 대기시간, DTMF 키별 호 분배룰을 등록한다.
  2. PBX 설정 > DID에서 DID를 추가하거나 수정한다.
  3. 연결 방식을 IVR 메뉴로 선택하고 생성한 IVR 메뉴를 지정한다.
  4. 지사 관리에서 해당 지사에 DID를 연결한다.
  5. .conf 미리보기와 운영 PBX 인입 테스트로 실제 분기 결과를 확인한다.

4.2 DID를 특정 상담원에게 직접 착신

  1. 상담원 설정에서 대상 상담원의 내선이 활성 상태인지 확인한다.
  2. PBX 설정 > DID에서 DID를 추가하거나 수정한다.
  3. 연결 방식을 내선 직결로 선택한다.
  4. 직접 착신 내선에서 상담원을 선택하고 저장한다.
  5. 부재, 무응답, 업무시간 분기가 필요하면 착신전환 설정 또는 1인 호 분배룰 연결을 검토한다.

4.3 호 분배룰의 외부 착신 방식 설정

  1. 호 분배룰 설정에서 분배룰을 추가하거나 수정한다.
  2. 외부 착신 방식을 선택한다.
  3. 순차/분배 방식이면 상담원 또는 상담원 그룹 멤버와 순위를 구성한다.
  4. 무조건 착신이면 대상 유형과 대상 값을 지정한다.
  5. 최대 대기시간, 링 타임아웃, 후처리 시간을 운영 기준에 맞게 조정한다.

4.4 착신전환 조건 설정

  1. 착신전환 설정에서 규칙을 추가한다.
  2. 대상 DID를 선택한다.
  3. 전환 방식을 외부번호, 내선, 호 분배룰 중 하나로 선택한다.
  4. 착신 조건을 즉시, 대기시간 초과, 상담원 없음 중 하나로 선택한다.
  5. 시간 조건이 있으면 적용 방식을 요일/시간 지정으로 바꾸고 시간표를 추가한다.

4.5 다중 국선 기본 발신 그룹 구성

  1. PBX 설정 > 트렁크에서 각 통신사 또는 회선별 트렁크를 등록한다.
  2. 트렁크의 Host, 포트, 인증, From Domain, 코덱, 표시번호를 입력한다.
  3. 같은 화면의 국선 그룹 영역에서 그룹을 추가한다.
  4. 멤버 트렁크와 우선순위를 지정하고 기본 발신 그룹을 활성화한다.
  5. .conf 미리보기에서 발신 경로에 국선 그룹 멤버가 반영되는지 확인한다.
  6. 운영 PBX에서 주 회선 장애 우회와 원복을 검증한다.

4.6 단축 발신 등록

  1. PBX 설정 > 단축 발신으로 이동한다.
  2. 단축번호, 대상번호, 표시명, 설명을 입력한다.
  3. 단축번호는 내선 번호나 외부 발신 패턴과 충돌하지 않게 정한다.
  4. 대상번호가 외부번호이면 기존 발신번호 정책과 국선 그룹 경로의 영향을 받는다.

4.7 번호 자원에서 설정 화면으로 이동

  1. DID / 내선 메뉴에서 DID, 내선, 호 분배룰 번호, 기능코드를 확인한다.
  2. 충돌 또는 확인할 항목의 설정 열기를 누른다.
  3. DID는 PBX 설정 > DID, 상담원 내선은 상담원 설정, 분배룰 번호는 호 분배룰 설정, 기능코드는 통화 현황 조회의 기능 안내로 이동한다.

7. 우선 적용 순서

  1. 운영 필수: DID, IVR, 호 분배룰, 착신전환, 내선 표시명, 내선 잠금, 시간 동기화.
  2. 운영 안정화: 공휴일, 시간별 라우팅, 대리응답 제한 기능, 번호 자원 충돌 확인.
  3. 발신 안정화: 트렁크 표시번호, 국선 그룹, 다중 국선 장애 우회 검증.
  4. 외부 연동: SMDR TCP Call Report 포트 개방, 타사 CID 프로그램 접속, 삼성 OfficeServ 계열 CDR 고정폭 레코드 수신/파싱 검증.
  5. 편의 기능: 단축 발신, 도움말 자동 구축, 공용 운영 가이드.
  6. 보류 유지: 실시간 감청, 키버튼/전화기 버튼, PBX COS 전체 복제, 포트 DB 초기화 일반 노출.
